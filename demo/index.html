Valida datos españoles
sin adivinar.

DNI, NIE, CIF, NIF especiales, IBAN, cuenta bancaria, Seguridad Social, teléfonos, códigos postales y matrículas. Cada error explica el motivo en castellano, y hay generadores de datos de prueba válidos.

npm install valida-es 

          

        


        

          
Datos de prueba válidos (ficticios)

          

          
Útiles para rellenar formularios y tests. Usa aleatorioConSemilla() para que sean reproducibles.

        

      


      

        
Uso

        
import { validarNif, validarIban, identificar } from 'valida-es'

const r = validarNif('x-1234567-l')
if (r.valido) {
  r.valor  // 'X1234567L' (normalizado)
  r.tipo   // 'NIE'
} else {
  r.motivo  // 'vacio' | 'formato' | 'longitud' | 'control' | 'pais' | 'rango'
  r.mensaje // 'La letra no corresponde: debería ser L.'
}

validarIban('ES9121000418450200051332').datos // { pais: 'ES', banco: { codigo: '2100', nombre: 'CaixaBank' } }
identificar('600 11 22 33') // { tipo: 'telefono', subtipo: 'movil', valor: '+34600112233' }
